# 🏏 Cricket Smash

**Cricket Smash** is a fast-paced, 1-minute mobile-first cricket web application designed for single-thumb portrait gameplay. Hit boundaries, unlock power bats, customize helmets & stadiums, and climb global leaderboards!

![Cricket Smash Mobile Preview](https://img.shields.format/badge/Mobile-Portrait_First-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ⚡ Features

- **📱 One-Handed Gameplay**: Optimized for vertical portrait screens with intuitive swipe & tap gestures.
- **⏱️ 1-Minute Blitz Mode**: Fast 60-second smash challenge ideal for quick gaming sessions.
- **🏏 Precision Timing & Shots**:
  - **Swipe Left**: Pull Shot / Square Cut (Leg side)
  - **Swipe Right**: Cover Drive / Off Drive (Off side)
  - **Swipe Up / Forward**: Straight Lofted Drive (Long-on / Long-off SIX)
  - **Swipe Down / Quick Tap**: Defensive block / Late cut
- **💥 Visual & Camera FX**: Slow-mo impact zoom on SIXES, screen shake, and crowd fireworks.
- **👕 Locker Room Unlockables**:
  - **Bats**: Classic Willow, Thunderbolt Bat (+15% Power, Lightning Trail), Flame Strike (+30% Power, Fire FX), Golden Champion (+50% Power).
  - **Helmets**: Classic Blue, Carbon Pro (+1 Wicket Armor), Royal Crown (+20% Score Boost), Cyber Visor (HUD Trajectory Arc).
  - **Stadiums**: Local Park, Royal Oval (Floodlit Arena), Cyber Arena (Neon), Colosseum (Golden Sand Arena).
- **🔊 Web Audio Synthesis**: Procedural sound effects for bat contact, pitch bounce, crowd roars, umpire whistles, and coin unlock chimes.
- **🏆 Global Leaderboard**: Persistent local score tracking with dynamic global competitor rankings.

## 🚀 Quick Start

No dependencies or build steps required! Simply clone and run any static server:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/cricket-smash.git
cd cricket-smash

# Run local web server
npx serve -p 8080 .
```

Then open `http://localhost:8080` in your web browser!

## 🛠️ Technology Stack

- **HTML5 Canvas**: 60 FPS 2D Perspective Game Rendering Engine
- **Vanilla JavaScript (ES6)**: Game Loop, AI, Timing Logic, Shop System & Leaderboards
- **Vanilla CSS3**: Responsive Portrait Viewport Frame, Glassmorphic UI & Animations
- **Web Audio API**: Real-time sound effect synthesis
